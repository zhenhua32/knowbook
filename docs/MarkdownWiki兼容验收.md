# Wiki 链接与图片嵌入

## 本期范围

| 写法 | 行为 |
| --- | --- |
| `[[文档|显示名称]]` | 显示指定文字，目标参与出入链、文档改名与移动维护 |
| `[[目录/文档.md|显示名称]]` | 根目录路径，可省略 `.md`；短名称只在标题唯一时解析 |
| `[[文档#章节文字|显示名称]]` | 跳转到章节，也接受现有章节 slug 和 HTML 自定义锚点 |
| `[[#章节文字]]` | 当前文档内跳转，展开遮挡目标的折叠章节 |
| `[[../目录/文档#章节]]` | 显式相对路径；来源移动后保持原目标 |
| `![[图片.png]]` | 导入时收纳图片，编辑与阅读显示，文件导出和备份携带图片 |

别名显示为纯文字，不执行其中的 HTML。表格中的分隔符按 GFM 要求写成 `\|`；源码定位和自动维护保留该转义。代码、数学、YAML、转义文本和图片替代文字中的示例不会被当作链接。

路径与显示名称分开处理。文档改名、跨目录移动、章节改名只维护目标，显式别名保持不变。重复章节使用已有稳定块身份维护；删除章节后保留失效目标，避免跳到另一个同名章节。

旧的 `[[块 ID]]` 和 `[[文档路径#块 ID]]` 继续生效。`#` 后内容优先匹配目标文档中实际存在的块 ID，然后匹配章节 slug／可见标题；生成的 UUID 块 ID 失效后不会猜测为同名章节。已有完整路径包含 `|` 时，优先保留该实际文档目标。

数据库版本 19 重建派生链接索引与出入链关系，并保留迁移前安全副本；升级不改写原有正文与块 ID。

## 图片与文件往返

- 带目录的 Wiki 图片路径从所选导入根目录解析；`./`、`../` 明确从当前文件目录解析。
- 单独文件名优先匹配根目录文件，否则只接受所选目录内唯一同名文件。多个同名图片会在导入报告中提示歧义并保留源码。
- 沿用既有目录边界、符号链接限制、附件字节／数量上限及事务回滚规则。原目录移除后，已收纳图片仍可显示。
- 单文件导出继续复制图片到同级 `.assets` 目录，备份使用统一资源目录。Wiki 图片源位置参与同一套 URL 改写，别名及其他文本保持不变。
- 普通 Markdown 导出保留 Wiki 写法。无 Wiki 扩展的阅读器可能显示源码；普通目录导出与向标准链接转换属于后续阶段。

## 明确边界

本期不包含整篇笔记／章节嵌入、外部 `#^块标识` 及 `^标识` 定义、音视频／PDF 嵌入、多级 `#章节#子章节`、图片尺寸参数、YAML aliases 属性自动匹配。未支持的笔记嵌入与外部块引用继续显示源码并出现在导入诊断中。

语法参考：[Obsidian 内部链接](https://obsidian.md/help/links)、[文件嵌入](https://obsidian.md/help/embeds)。上述范围是 KnowBook 实现的明确子集，不代表所有其他应用方言兼容。
