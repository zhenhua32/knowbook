# Markdown 标准与往返验证

第一阶段使用固定的官方样本验证实际应用解析器、块转换、编辑器草稿、SQLite 和文件恢复，不将底层解析库单独通过视为应用已通过。

## 规范结果

| 规范 | 样本数 | 与官方预期语义一致 | 明确的产品差异 | 三轮普通 Markdown 往返 | 三轮元数据备份往返 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CommonMark 0.31.2 | 652 | 575 | 77 | 652 | 652 |
| GFM 0.29-gfm | 677 | 598 | 79 | 677 | 677 |

规范统计针对解析和序列化的语义。块式阅读当前沿用统一的块间距；紧凑／松散列表的视觉区分与列表分组呈现纳入后续阅读、编辑体验验收。

往返比较保留正文、链接目标、标题层级、列表边界、紧凑／松散列表、代码空白和空代码块。比较器只统一 HTML 布局空白、布尔属性、空元素写法，以及等价的表格 `align` / `text-align` 表示。普通导出的标记与缩进可以规范化；不承诺逐字节复原原文件。

所有样本均执行三轮普通 Markdown 与备份导出／再导入，并检查后续导出的稳定性。备份同时比较恢复后的块内容与格式信息。1329 条样本还经过编辑器草稿规范化、SQLite 写入和读取后再比较语义。

## 产品差异没有跳过

| 原因 | CommonMark | GFM | 当前规则 |
| --- | ---: | ---: | --- |
| 原始 HTML | 72 | 71 | 作为 Markdown 中的文字处理，不执行 HTML |
| 自动链接 | 4 | 4 | 自动链接扩展始终开启；两份规范的基础自动链接章节有把裸 URL 当文字的示例 |
| Wiki 链接 | 1 | 1 | `[[…]]` 优先按 KnowBook 文档引用识别 |
| 协议范围 | 0 | 3 | 不识别 XMPP 裸链接，保留文字 |

每一条差异在 `tests/fixtures/markdown-spec/policy-differences.json` 中记录原因和预期输出，仍执行断言与全部往返验证。新增差异、差异行为退化、过时记录都会使检查失败。因此以上结果不等于“CommonMark / GFM 完全兼容”。样本之外的输入仍可能存在未发现的问题。

## 本阶段修复

- 保留列表使用的标记、紧凑／松散状态，以及相邻列表边界；新建后续列表项继承格式。
- 按四列制表位处理 Tab；保留列表内缩进代码和超出九位显示计数后的合法列表标记。
- 保留多行 Setext 标题及标题末尾的字面量 `#`。
- 处理列表、引用中的省略标记续行，避免导出时正文变成标题、子列表；代码跨度内不插入字面反斜杠。
- 区分真正的空代码围栏与包含一个空白行的代码围栏；代码高亮语言检测不再改写原始围栏信息。
- 恢复深层任务的勾选状态；保留空文档为空，不额外插入提示正文。
- 补齐 `www.` 自动链接、URL 中部括号、尾部标点和实体边界。
- 数据库升级到版本 14，保存格式信息；沿用升级前备份，旧笔记不批量改写。

## 验证入口

```text
npm run test:markdown-spec
npm run typecheck
npm run typecheck:system-plugin-examples
npm test
npm run build
npx playwright test --grep @electron
```

`test:markdown-spec` 生成 `test-results/markdown-spec-report.json`，逐项列出全部样本的语法、差异分类、往返与稳定性结果。全量测试额外包含文件导入、关闭数据库后重开、普通文档导出／再导入、备份恢复、深层任务和数据库迁移。Electron 验收覆盖真实导入、编辑、保存重载、阅读以及文件导出。

规范来源及许可见 [样本说明](../tests/fixtures/markdown-spec/README.md)。后续高级语法、编辑体验、链接更新和性能对标仍按 [提升计划](Markdown提升计划.md) 推进。
