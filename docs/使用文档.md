# KnowBook 使用文档

## 产品说明

KnowBook 是本地优先的知识管理桌面应用。SQLite 是唯一事实源，Markdown 用于备份、恢复和单文档导出。

主要功能：

- 文档树和块编辑器
- 完整搜索、组合筛选与保存检索
- 页面链接、块引用、出链和反向链接
- 统一 Database 工作台（Table / Board / Cards）
- AI 问答、选区编辑、自动摘要和相关笔记检索
- Markdown 快照备份与恢复
- 网页剪藏和浏览器扩展桥接
- 隔离的 v2 动态插件与 Full Trust v3 系统插件

相关笔记检索当前基于标题、摘要和块正文做本地关键词匹配，不使用 Embedding 或向量数据库。

## 安装、启动与构建

开发模式：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建产物写入 `out/`。本地打包：

```bash
npm run dist
```

安装包和解包目录写入 `release/`。一次性执行打包和本机产物检查：

```bash
npm run release:verify-local
```

## 首次使用

1. 在侧栏选择界面语言。
2. 创建或打开一篇文档；也可点击侧栏“从模板新建”，从会议纪要、读书笔记或项目复盘开始。
3. 在配置中心检查实际数据库和备份路径。
4. 如需 AI，填写 Base URL、Model 和 API Key，再启用 AI。
5. 手动执行一次备份，并确认备份目录中生成了 Markdown 文件。

开发模式和未打包应用不支持自动更新，这是正常状态。

## 界面导航

侧栏包含：

- 文档：文档树、编辑器、关系和网页剪藏。
- 总览：工作区统计、最近文档、事件和插件卡片。
- Database：在统一工作台中浏览全部文档和自定义数据库。
- AI 助手：AI 配置状态、问答和相关笔记。
- 插件中心：动态插件与系统插件的状态、安装、启停、诊断和恢复。
- 配置中心：语言、更新、备份和浏览器桥接。
- 搜索：完整结果、组合筛选、排序、分页与保存检索。

常用全局快捷键：

- `F1`：打开或关闭快捷键帮助。也可点击侧栏底部的“快捷键帮助”，或在命令面板搜索“快捷键”。帮助支持按操作名、组合键搜索和分类筛选，并标明适用场景；macOS 显示 Command / Option 按键。
- `Ctrl/Cmd + 1…6`：切换主要页面。
- `Ctrl/Cmd + K`：打开或关闭快速搜索，点击“查看全部结果”进入完整搜索。
- `Ctrl/Cmd + Shift + F`：打开完整搜索；从快速搜索中使用时带入当前关键词。
- `Ctrl/Cmd + Shift + P`：打开命令面板。
- `Ctrl/Cmd + Shift + N`：在应用内打开快速记录；在记录对话框中按 `Ctrl/Cmd + Enter` 保存。
- `Ctrl/Cmd + F`：在文档页打开或关闭块搜索。
- `Ctrl/Cmd + S`：保存当前文档的标题、摘要和正文；在源码对话框中应用源码更改。
- `Alt + ArrowLeft / ArrowRight`：文档导航后退或前进。
- `Escape`：关闭搜索或清除当前块选区。
- Database 页内 `/`：聚焦记录搜索。
- Database 页内 `Ctrl/Cmd + Shift + L`：聚焦数据库选择器。
- Database 页内 `Ctrl/Cmd + Shift + V`：聚焦新建视图。

## 文档与块编辑器

### 文档树

- 使用文档树上方的新建按钮创建根文档。
- 使用文档菜单创建子文档、移动或删除文档。
- 同一父级下标题必须唯一；冲突时应用会拒绝移动，或在保存标题时生成唯一名称。
- 删除文档会先保存草稿，再把当前文档放入回收站，并把直接子文档提升到被删除文档的父级。
- 进入其他文档前，应用会尝试保存当前草稿；树结构校验失败时会阻止跳转。

### 模板与快速记录

点击侧栏 **从模板新建**，选择内置的“会议纪要”“读书笔记”“项目复盘”，或自己保存的模板。创建前可以修改文档标题、选择父目录；默认在根目录创建。生成的文档拥有独立的文档和块 ID，后续修改不会改变模板或来源文档。

在文档右上角 **更多操作 → 保存为模板**，为模板填写名称。模板保存当前编辑器的标题、摘要和正文草稿，不需要等待自动保存完成。模板正文和摘要可使用 `{{date}}`、`{{title}}`：创建文档时分别替换为当天日期（`YYYY-MM-DD`）和新文档标题。模板选择器可删除自定义模板，内置模板保留；删除模板不会删除已经创建的文档。

临时想法可点击侧栏 **快速记录**，或在应用内按 `Ctrl/Cmd + Shift + N`。正文必填，支持 Markdown；标题可留空，也可选择父目录。点击“保存记录”或按 `Ctrl/Cmd + Enter` 后创建并打开文档。点击“取消”或按 `Escape` 不会新增文档。

命令面板中也可执行“从模板新建”“保存为模板”“快速记录”；“保存为模板”需要先选择一篇文档。

自定义模板保存在本机 SQLite，目前不包含在 Markdown 备份和 WebDAV 同步中。Markdown 恢复会保留目标知识库现有模板；完整 SQLite 安全副本包含模板，数据库恢复会以副本中的模板替换当前模板。通过模板或快速记录创建的文档会按普通文档参与备份和同步。

### 块类型

当前包括：

- 一级、二级和三级标题
- 段落
- Todo
- 引用
- 无序列表
- 有序列表
- 代码块
- 数学公式
- 分割线

输入 `/` 可打开块命令。支持常见快捷前缀，例如 `#`、`##`、`>`、`-`、`1.`、`- [ ]`、`- [x]`、`$$`、`---` 和三反引号。

### 块操作

- `Enter`：续写标题、列表或待办。
- `Ctrl/Cmd + Enter`：在当前块下方插入新块。
- `Alt + Enter`：在光标处分裂块。
- `Tab / Shift + Tab`：调整可嵌套块的层级。
- `Alt + ArrowUp / ArrowDown`：移动当前块或连续块选区。
- `Ctrl/Cmd + Shift + D`：复制当前块或选区。
- `Delete / Backspace`：删除块选区；在块首使用 Backspace 可降级部分块格式。
- 拖拽块时左右移动，可预览新的父级和深度。
- 多行粘贴会拆为多个块；存在连续块选区时可整体替换。

撤销历史对连续输入采用短暂防抖，刚输入后即可通过菜单或快捷键撤销。分块、缩进等结构操作可单独撤销，并恢复对应编辑位置与选区；撤销后继续输入会结束原来的重做分支。标题、摘要与其他输入框保留各自的文字撤销历史。

需要跨多个块选择文字时，在文档右上角菜单选择 **编辑 Markdown 源码**。该编辑区包含完整正文，支持跨段格式、复制粘贴、撤销／重做与 `Ctrl/Cmd+S` 应用；编辑区、格式工具栏和按钮上的保存及撤销快捷键行为一致。应用后自动保存，也可在块视图撤销整次更改。未删除内容的块 ID、标签和高亮会保留。点击“取消”放弃本次尚未应用的源码更改。源码弹窗会阻止全局切页、搜索和快速记录快捷键，`F1` 仍可查看帮助。该入口不编辑文档标题和摘要。

中文输入法选词期间，回车、方向键、退格和 Tab 交给输入法处理；候选文字不会触发块快捷操作或写入自动保存与撤销历史，确认输入后恢复。

文档标题旁显示“待保存／保存中／已保存／保存失败”。失败时草稿仍在，点击保存或按 `Ctrl/Cmd+S` 可重试，继续编辑也会重新尝试自动保存。保存中再次保存或切换文档，会等待当前保存完成，并保存期间新增的修改。工具栏和侧栏菜单的“复制 Markdown”“导出 Markdown”均包含当前打开文档的最新草稿与标题，无需等待自动保存完成。

### 长文档阅读与导航

文档顶部的导航栏在滚动时保持可用，显示当前章节和滚动进度。点击“大纲”可以筛选一级、二级标题并跳转，跳转不会直接进入编辑状态。

点击“阅读”可查看当前草稿的排版效果，正文编辑控件会隐藏；点击“编辑”返回修改，尽量保留正在阅读的内容块与相对位置。阅读视图可以勾选待办，菜单与快捷键均可撤销、重做本次阅读期间的任务操作；此前的正文编辑不在此撤销范围内。

阅读位置按文档在本机记忆，支持切换文档、历史返回和重启后重新打开文档。定位使用内容块 ID，前文增删后仍尽量回到原来的段落；原块被删除时退回邻近的滚动位置。最多保留最近 100 篇文档的位置，目录、搜索和引用跳转优先于记忆位置。

标题左侧和大纲中的小箭头可以折叠章节，一级标题包含下面的二级标题，二级标题包含直到下一个同级或更高层级标题之间的内容。大纲提供“全部折叠”和“全部展开”。折叠不会删改正文，也不会影响全文导出；折叠状态按文档在本机记忆，最多保留 100 篇，重启后仍可恢复。

在大纲中点击章节旁的“只看”，或点击“只看本章”，可专注阅读、编辑一个章节。顶部“显示全文”返回整篇文档。专注状态也会记忆；本章模式下，在段落中连按两次 `Ctrl/Cmd + A` 选中本章所有块，底部“新增块”在本章末尾创建普通段落。收起正在编辑的章节时光标移至可见标题，保持编辑上下文不变后展开会恢复先前的光标或选区。

点击“查找”或按 `Ctrl/Cmd + F` 打开文内搜索。输入关键词后按 `Enter` 定位第一个结果，再次按 `Enter` 跳到下一个；`Shift + Enter` 返回上一个，`Esc` 关闭。搜索始终覆盖全文，定位会展开目标所在的折叠章节与列表，结果摘要显示命中附近的文字。专注本章时，目录、搜索和引用跳到其他章节会自动切换到目标章节。

### Markdown 与引用

支持 H1–H6、嵌套列表、任务列表、引用、代码、GFM 表格及常用行内样式。粘贴、阅读、复制与导出使用统一语法，详细规则见 [Markdown 兼容性](Markdown兼容性.md)。

- `[[文档名]]`：仅当标题在工作区唯一时解析。
- `[[路径]]`：按完整文档路径解析。
- `[[块ID]]`：引用当前文档中的块。
- `[[路径#块ID]]`：引用另一文档中的块。
- 按住 `Ctrl/Cmd` 点击引用可跳转。

页面级 `[[文档名]]` 和 `[[路径]]` 会进入出链/反向链接索引。跨文档块引用目前可预览和跳转，但不会作为页面链接写入出链/反向链接索引。

### 单文档导出

文档菜单支持复制或保存 Markdown。当前打开文档导出最新草稿与标题，包括折叠或专注模式隐藏的内容；其他文档导出已保存的内容。

## 完整搜索

点击侧栏 **搜索** 或按 `Ctrl/Cmd + Shift + F` 打开完整搜索。也可在 `Ctrl/Cmd + K` 快速搜索中输入关键词，再点击 **查看全部结果**。快速搜索显示部分匹配，完整搜索显示真实总数，支持分页查看全部匹配。

搜索范围可选“文档和内容块”“仅文档”或“仅内容块”：文档搜索标题、路径和摘要，内容块搜索正文。混合范围会同时显示文档和内容块，因此同一文档可有多条结果。匹配方式包括 **包含所有词**、**包含任意词**和 **完整短语**；关键词按空白分隔，完整短语要求文字顺序连续一致。留空关键词也可以使用筛选浏览内容。

目录筛选包含所选文档及其所有后代。标签按块标签筛选，内容类型按块类型筛选；同时选择标签和类型时，需由同一内容块满足。文档结果要求文档包含满足这些条件的块。更新时间按文档更新时间筛选，开始与结束日期包含本机时区的整天。可按相关性、最近更新或最早更新排序，并调整每页条数。

结果会高亮命中关键词，提供文档路径、摘要和更新时间。点击 **打开文档** 打开对应文档，点击 **定位内容块** 跳到命中的段落，也可以复制链接。打开结果后再返回搜索页，会保留本次关键词、筛选和页码；草稿保存失败时会保留搜索与编辑草稿，修复后可重试打开。

展开 **保存与加载检索**，填写检索名称，点击 **保存检索** 保存当前关键词、筛选、排序和每页条数。选择已保存检索后点击 **加载检索** 从第一页恢复条件；修改条件后可 **更新检索**，或另存为新检索。删除检索不会删除文档。

已保存检索保存在本机 SQLite，目前不包含在 Markdown 备份和 WebDAV 同步中。搜索覆盖已保存的文档内容，不识别图片中文字或附件文件正文。

## 网页剪藏

### 应用内 URL 剪藏

1. 在文档树中选中父文档。
2. 展开文档辅助区。
3. 在网页剪藏输入框粘贴 `http` 或 `https` URL。
4. 执行剪藏。

应用会提取正文、常见元数据和图片，并把图片保存到 userData 下的资源目录。相同来源 URL 与内容哈希已经存在时，会复用现有文档。

默认阻止访问本机和私有网络目标。只有显式设置开发环境变量 `KNOWBOOK_ALLOW_PRIVATE_WEB_CLIP=1` 才会放开此限制。

### 浏览器扩展桥接

1. 在配置中心启用浏览器桥接。
2. 复制扩展提交地址和授权令牌。
3. 在 Chromium / Edge 中加载仓库的 `web-clip-extension/`。
4. 把提交地址和 Bearer token 填入扩展。
5. 在目标页面执行剪藏。

桥接服务只监听 `127.0.0.1`，默认端口是 `3210`。修改端口或重置令牌后，需要同步更新扩展配置。授权令牌等同本机写入凭据，不要公开分享。

扩展的详细说明见 [web-clip-extension/README.md](../web-clip-extension/README.md)。

## Database

Database 页面是一套统一工作台，不再要求先选择“文档目录”或“独立数据库”模式。页头的数据库选择器固定包含“全部文档（系统）”，并列出所有自定义数据库；切换来源后，视图标签、工具栏和数据画布保持在相同位置。

页面从上到下分为：数据库页头、保存视图标签、视图工具栏和单一数据画布。工具栏可调整搜索、组合筛选、多字段排序、分组、字段显隐和 Table / Board / Cards 布局。变更后点击“保存更改”会写回当前视图，也可以另存为新视图。

### 全部文档

“全部文档”以工作区文档为记录，标题点击后进入文档编辑器。支持以下自定义字段：

- Text
- Select
- Multi-select
- Date
- Checkbox

Table 视图用于直接编辑字段。Board 可按父级、Select、Multi-select、Checkbox、Date 或 Text 分组；拖动卡片会更新对应字段值。系统字段可在字段抽屉中隐藏，但标题不能隐藏或删除。

### 自定义数据库与记录

自定义数据库拥有自己的字段、记录和保存视图。每条记录都有必填标题，可选关联一篇文档。点击记录标题打开详情抽屉；如已关联文档，可从抽屉跳转到文档。支持：

- Cards / Table / Board
- 文档关联
- 多条件字段筛选和多字段排序
- 按字段分组
- 保存字段显隐、顺序、列宽、卡片摘要字段和布局
- 批量字段应用、清空、解绑和删除
- 数据库、字段、视图和记录的应用内删除确认

点击“字段”打开字段管理抽屉，可新增、重命名、维护选项、显隐、调整当前视图顺序或删除字段。字段删除会同时删除已有值，建议先执行 Markdown 备份。

## AI

### 配置

在配置中心填写：

- Base URL：OpenAI-compatible API 根地址，例如 `https://api.openai.com/v1`。
- Model：服务端可用的模型名。
- API Key：保存在本地 SQLite 设置中。
- Enabled：总开关。
- Related notes：允许问答使用本地关键词相关笔记。
- Auto summary：文档保存后自动生成摘要。

Base URL 应填写 API 根地址，不要填写完整的 `/chat/completions` 地址；应用会自动追加该路径。

### 功能

- 文档问答：把当前文档和可选的相关笔记发送给配置的模型。
- 选区编辑：摘要、改写、转 Markdown 表格或自定义指令；先预览，再决定是否替换。
- 自动摘要：内容达到最低长度且摘要仍为默认值时触发。
- 手动自动化：只运行当前已启用的自动化。

AI 请求会把相应笔记内容发送到你配置的 API 服务。处理敏感内容前，请确认服务端的数据政策。

## 图片与附件

- 点击文档右上角的回形针 **图片与附件**，选择文件或拖进弹窗，插入到正文末尾。弹窗列出当前文档引用的本地附件及文件大小。
- 在正文中拖入文件，或在编辑块中粘贴截图，可在当前位置插入；在代码、公式等源码块中会新增独立段落，保留原有源码。支持撤销和重做。
- Markdown 源码编辑器也支持选择、拖拽和粘贴文件。插入后点击“应用更改”才会写入正文；取消不会修改正文。
- 点击图片可放大预览、缩放、查看原始大小，按 Esc 关闭；本地图片可另存为。附件卡片可通过系统默认应用打开、另存为或在文件夹中显示。可执行文件打开前会额外确认。
- 单个文件最大 25 MB，每次最多 20 个、合计 100 MB。导入失败会显示原因；导入过程中若切换文档，不会将附件插入另一篇文档。
- 文件复制到 `userData/storage/assets/attachments/`，相同内容和名称会复用已有副本，同名不同内容互不覆盖。图片使用标准 Markdown 图片引用，其他文件使用普通链接；PNG、JPEG、GIF、WebP、AVIF、BMP、ICO 可内嵌显示，SVG 等其他格式作为附件保存。
- 删除正文引用不会删除附件文件，回收站、文档历史及撤销仍可使用原附件。Markdown 导出和版本备份会复制当时正文引用的本地附件，跨目录恢复时重新建立链接。完整迁移工作区时，应一并保留 SQLite 和整个 `storage/assets/` 目录；SQLite 安全副本本身不包含附件字节。

## 备份、恢复与数据位置

### 数据位置

默认路径基于 Electron `app.getPath('userData')`：

```text
<userData>/
  storage/
    knowbook.db
    knowbook.db-wal       # 运行时可能存在
    knowbook.db-shm       # 运行时可能存在
    assets/
    plugin-revisions-v2/
  backups/
    markdown/
    system-plugins/
  system-plugins/
    artifacts/
    runtime/
    data/
    logs/
```

“总览”会显示当前实例实际使用的数据库和备份路径。测试或开发环境可以通过 `KNOWBOOK_USER_DATA_DIR` 覆盖 userData。

### Markdown 备份

- 应用启动后会立即执行一次备份，之后按固定间隔备份。
- 正常退出时会尝试再执行一次备份。
- 配置中心可手动触发。
- 最新完整快照仍写入原备份目录；上一个快照会移入同级 `markdown-history/`。自动保留最近 10 份，以及近 30 天每天最新的一份（按 UTC 日期），超过策略的旧版本才会被清理。
- 文档 frontmatter 保存文档 ID、路径、摘要、结构化字段和块元数据。
- 独立 Database 写在备份目录的 `__knowbook/databases/` 下。

### 恢复与普通 Markdown 导入

配置中心 → **数据恢复 → 查看备份版本** 可以选择已有快照恢复，无需手动寻找目录。确认前会显示创建、更新和删除数量，并在恢复前创建 SQLite 安全副本。旧版没有版本信息的快照也可以继续恢复。取消预检确认不会修改数据。

### 回收站与文档历史

- 侧栏底部或配置中心 → **打开回收站**：按标题、路径或日期筛选，预览删除时的内容并恢复。回收站不会自动清空，永久删除需要再次确认。
- 回收站恢复保留文档 ID、块 ID、标题、摘要、正文、块标签和高亮；原目录已不存在时恢复到根目录，同级重名时自动增加编号。删除时上移的子文档保持当前位置。
- 关联的数据库记录和字段在对应数据库、字段仍存在时恢复；已删除字段或已移除的选项不会被重新创建。恢复失败会回滚整次操作，保留回收站副本。
- 文档右上角 **更多操作 → 文档历史**：并排预览所选版本和当前版本。修改前自动建立检查点，连续编辑每 5 分钟最多一份，每篇文档保留最近 100 份。删除和恢复前会额外建立检查点。
- 恢复历史会替换标题、摘要和正文（含块元数据），不改变当前目录和数据库字段；恢复前的内容会成为新的历史记录，可再次恢复。如果预览期间文档已变化，需重新加载后再恢复。
- 文档历史从升级后的修改开始积累；无法补回升级前已丢失的内容。回收站和历史保存在本机 SQLite 中，不包含在 Markdown 快照中；数据库级安全副本会保留它们。永久删除不会擦除已有备份中的副本。

### 从目录导入

应用会先判断所选目录是否包含标准位置的 KnowBook 清单 `__knowbook/databases/index.md`：

- 完整 KnowBook 快照：创建或更新快照中的文档，并删除快照范围内已不存在的文档；独立 Database 同样按清单同步。
- 普通或旧版 Markdown 目录：只创建或更新识别出的文档，不删除现有文档或独立 Database。

完整快照恢复仍可能删除工作区内容。执行前务必：

1. 关闭其他 KnowBook 实例。
2. 复制整个 `storage/` 目录，至少保留数据库及可能存在的 WAL/SHM 文件。
3. 确认所选完整快照目录由 KnowBook 生成。
4. 先在测试数据目录验证重要备份。

### 重置本地数据

不要使用文档中写死的用户名路径。需要重置时：

1. 在“总览”确认实际数据库路径。
2. 完全退出应用。
3. 把对应 userData 目录重命名为一个备份目录。
4. 重新启动应用，确认新工作区正常后再决定是否删除旧目录。

## 插件管理

插件中心管理两个独立通道：

- **Plugin Platform v2**：AI 创建的动态插件与已安装市场包。检查器显示 capability 权限、最近 revision 和运行日志，并提供启停、隔离恢复、卸载与 AI 定制入口。
- **System Plugin v3**：从目录或 ZIP 准备安装，核对插件 ID、版本、内容哈希和依赖计划，由用户确认完整本机访问风险。安装、启用和回滚后按状态提示重启；插件中心提供 Main/Renderer/后台服务状态、数据与日志目录、安全模式和恢复操作。

应用内置的 v3 **主题切换** 无需单独安装，首次启动自动启用。在配置中心可选择云白、暖纸、青苔、海湾、午夜、紫夜，或跟随 KnowBook 原有外观。插件中心标注“来源：内置”，支持停用和重新启用；版本随应用更新，保留之前的主题选择和停用状态。

旧 v1 插件系统已移除。仓库和 userData 下的旧 `plugins/` 目录不再自动扫描，也没有旧版重扫、重载或安装入口。旧源码和历史数据保留，自定义插件需改写成 v3 后重新安装；不能仅修改 manifest 就假定旧 SDK 可用。

AI 页面同时提供 Plugin Platform v2 工作台。你可以直接描述想要的 KnowBook 改动；助手会先检查平台能力，生成并验证不可变插件 revision，展示插件 id、revision id、变更和权限差异，然后把精确 revision 激活到当前工作区。后续对话可以继续检查、修改、停止或回滚同一个插件。

## 插件开发

### Plugin Platform v2

动态 v2 插件只允许导入应用提供的精确版本 `@knowbook/std/*` 模块，当前基础模块为 `@knowbook/std/plugin@1.0.0`。运行时不提供 Node.js、Electron、文件系统、网络、shell、定时器或 `npm install`；文档读写、插件状态和 UI 通知必须通过 manifest 声明、绑定精确 revision 并由 host broker 校验的 capability 完成。

AI 生成插件从创建起就是 workspace 安装；应用重启时会恢复仍处于启用状态且授权有效的安装，但不会静默重放未完成的助手工具。仓库内置的 `activity-pulse-v2` 演示了 Dashboard 卡片、文档动作、工作区事件订阅和异步 capability 调用。

### System Plugin v3

v3 包声明 `schemaVersion: 3`、`trust: "full"`、`fullAccess: true`，并明确指定 `entries.main/renderer/service` 至少一个入口。它可以使用完整 Node/Electron、任意 npm 依赖和宿主 React；风险声明用于确认和审计，不是隔离权限。

- [Activity Pulse](../plugins/activity-pulse/README.md)：从旧插件迁移的 v3 实例，保留最新文档活动卡片、从首个非空块生成摘要和持久化摘要前缀。
- [主题切换](../plugins/theme-switcher/README.md)：随应用内置并默认启用的六款浅色 / 深色预设，在配置中心点击应用、自动保存；可跟随应用外观，停用后恢复原样。
- [v3 Starter](../examples/system-plugin-v3-starter/README.md)：展示 Main、Renderer 和后台服务。
- [v3 开发指南](system-plugin-v3-development.md)：类型入口、生命周期、依赖构建、状态迁移、资源清理与故障恢复。

外部插件在插件中心选择工程目录，确认精确安装内容后重启。源码修改后重新准备并确认安装；内置主题插件则随应用重新构建和更新，不要编辑宿主发布的 artifact。旧 v1 的 `activate(api)`、`contributeDashboardCard` 和 `contributeSetting` 接口已删除，需要改用 v3 Main 服务与 Renderer 插槽，不能由兼容层执行。

## WebDAV 跨设备同步

打开 **配置中心 → WebDAV 跨设备同步**，填写服务地址、用户名、服务商生成的应用密码和远端目录。先点击“保存同步设置”，再“测试连接”和“立即同步”。其他设备填写相同的服务地址、账号和目录；初次同步合并两端已有文档，不自动删除任一端原有内容。

| 服务 | WebDAV 地址 |
| --- | --- |
| 坚果云 | `https://dav.jianguoyun.com/dav/` |
| Koofr | `https://app.koofr.net/dav/Koofr/` |
| InfiniCLOUD | 使用账户 My Page 显示的专属 WebDAV 地址 |
| Nextcloud | `https://你的域名/remote.php/dav/files/用户名/` |

远端目录默认 `KnowBook`，请使用本应用专用目录。更换地址、账号或目录需要重新填写应用密码。以上是配置示例，实际兼容性以连接测试为准；服务必须支持 GET、PUT、MKCOL、DELETE，以及基于非弱 ETag 的 `If-Match` 条件写入。下载响应缺少可用 ETag 时，会尝试 HEAD 和 `PROPFIND Depth: 0` 的文件属性，再按该版本重新下载，避免把旧内容与新版本号配对。部分服务返回不带引号的 ETag，应用会保留原始值并验证其条件写入能力；不会将弱 ETag 强行视为强版本标识。

首次创建同步清单优先使用 `If-None-Match: *`。若服务忽略此条件，会检查 `MOVE` 的 `Overwrite: F` 是否能拒绝覆盖已有文件，只有验证通过才使用临时文件移动来安全创建清单。服务不支持这些并发保护时，应用会停止同步并说明原因，不会退化为直接覆盖清单。

勾选“启用自动同步”后，应用启动时同步一次，运行期间默认每 5 分钟同步。离线或请求失败会显示原因，并在后续周期重试，也可手动重试。“停止本次同步”会取消当前请求；要长期停用，请取消自动同步并保存。坚果云请求会按免费接口额度放慢发送，首次同步大量文档可能耗时较长。

同步时会每秒刷新当前阶段、文档与数据库处理数量、附件处理数量、当前文件和已用时间。进度条表示本阶段的处理进度；连接检查与保存结果等无法预先确定工作量的阶段显示持续运行状态。遇到服务频率限制时会提示等待时间，重新打开配置中心也能查看正在进行的同步。

同步范围与冲突处理：

- 文档按篇同步，包括正文、标题、摘要、块 ID、目录关系和顺序；本地图片、附件以内容哈希去重传输，下载校验成功后才应用文档。未导入工作区的本机文件链接需要先导入为附件。
- 数据库、字段、视图和记录作为一个整体进行版本比较。两端同时修改这个整体时，需要选择保留本地或远端版本。
- 两端修改同一文档时，以最近共同版本比较双方改动。不同字段、不同正文块，以及同一段内位置明确且不重叠的文本修改会自动合并，保留块 ID 和附件引用。
- 重叠修改显示为“待处理冲突”。展开卡片可以查看双方完整版本和共同版本；“逐项合并”只需处理重叠字段或正文块，选择本地、远端，也可为标题、摘要和正文块输入自定义内容。处理完全部项目后可预览合并结果，再保存方案；其他独立改动会一起保留。两端同时改动正文块结构、类型或顺序时，需要整体选择正文；没有可用共同版本时，需要选择整篇版本。
- 冲突也可直接选择本地、远端或“两份都保留”。双份保留会让原文档采用远端状态，并在根目录生成本地冲突副本；若本地已删除，则保留原文档的删除状态并生成远端冲突副本。一端删除、另一端编辑的情况不会自动合并。
- 方案保存后显示“待同步应用”，点击“立即同步”才应用；也可取消处理方案。方案与已查看的双方版本绑定，任一版本再次改变时会重新提示，避免过期选择覆盖新内容。
- 删除以标记传播，远端删除的本地文档进入本机回收站；恢复后作为新修改同步。历史记录和回收站已有内容不跨设备复制，接收覆盖前会建立本地历史检查点。
- 同步期间的本地编辑会延后远端更新。若编辑器持有旧版本，保存会被阻止，保留当前草稿并提示复制草稿后重新打开文档。
- AI 密钥、WebDAV 密码、插件、AI 会话和设备设置不上传。WebDAV 密码只返回“已保存”状态，由操作系统凭据存储保护；系统加密不可用时需先配置系统凭据存储。
- 默认要求 HTTPS；可信局域网的 HTTP 服务需要显式开启 HTTP。云端文档和附件目前没有端到端加密。
- 单附件上限 25 MB，单篇文档或数据库整体上限 16 MB。远端历史对象与删除标记暂不自动清理，请关注存储额度。首次上传会占用相应流量，后续只传变更；没有变化时仅读取清单。

本地 SQLite 始终位于各设备自己的数据目录。不要将正在使用的数据库文件交给网盘同步，也不要手动修改远端 `manifest.json`、`objects` 和 `assets`。若远端清单丢失或工作区被替换，应用会停止同步，防止把缺失误认为删除；可恢复原目录或设置一个新的独立目录重新合并。WebDAV 同步不能替代独立备份。

协议参考：[WebDAV RFC 4918](https://www.rfc-editor.org/rfc/rfc4918)、[坚果云接口说明](https://help.jianguoyun.com/?p=2064)、[Koofr 连接说明](https://koofr.eu/help/koofr_with_webdav/how-do-i-connect-a-service-to-koofr-through-webdav/)。

## 常见问题

### AI 按钮不可用

确认 AI 已启用、Base URL 和 Model 非空、API Key 已保存，并且服务端支持 OpenAI-compatible `/chat/completions`。

### 开发模式显示“不支持自动更新”

自动更新仅在正式打包版本中启用。

### 插件未出现

外部 v3 插件需要先在插件中心选择目录或 ZIP、确认安装并按提示重启；仅把文件放进 `plugins/` 目录不会加载。内置主题插件若未显示，请检查是否停用或进入了安全模式。检查 manifest 和声明入口、版本兼容性及依赖日志。v2 插件则检查是否已激活对应 revision、是否停用或被隔离，并查看运行诊断。

### 原生 SQLite 模块加载失败

执行：

```bash
npm run postinstall
```

这会为当前 Electron 版本重建 `better-sqlite3`。
