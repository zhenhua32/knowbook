# Markdown 链接与文件互通验收

这是 [Markdown 提升计划](Markdown提升计划.md) 的第四阶段。目标是让文档组织变化后仍能访问原目标，并能发现无法恢复的链接。

## 已实现

| 场景 | 行为 |
| --- | --- |
| 文档改名、移动、删除父目录 | 按原目标维护入链，并从新目录重算出链；对子文档同样生效。 |
| 章节改名、同名章节重排 | 使用稳定块身份识别原章节；文档标题锚点、引用中的标题也参与解析。 |
| 删除与恢复章节 | 删除后使用失效标记保留原身份，避免跳到其他同名章节；恢复原块可重新关联。 |
| Wiki 引用 | 维护已确定的文档或跨文档块引用；标题中的 Wiki 标签变化也继续维护指向该标题的普通锚点。 |
| 精确源码修改 | 只改目标位置；保留标签、标题、查询参数、引用定义、脚注、表格和列表结构；代码和数学公式不被误改。 |
| 出链与反向链接 | 普通 Markdown 的文档目标加入已有关系面板和链接计数。 |
| 断链检查 | 文档“更多 → 检查链接”；先保存草稿，检查整篇文档并分类显示问题，可定位来源并展开隐藏章节。 |
| 导入恢复 | 以 ID、完整路径匹配覆盖；普通目录保留其他文档，完整备份按清单恢复。确认界面说明覆盖、附件和安全副本规则。 |
| 批量一致性 | 导入内容作为最终来源；未被覆盖的其他文档按恢复前后的最终路径更新。中间路径不触发重复重写；失败回滚正文及索引。 |
| 文件互通 | 相对图片与附件随文件迁移；自动链接形式的托管附件也可导出。完整导出不受折叠或聚焦影响。 |

数据库升级到版本 15。新的来源索引可重建，与正文变更共享 SQLite 事务；升级前沿用数据库安全副本。日常维护按目标路径查找相关来源，不扫描全部工作区正文；迁移和批量恢复会重建索引。

## 验证样本

- `tests/shared-markdown-link-maintenance.test.ts`：嵌套列表、提示块、表格、脚注、引用定义的准确位置；重复标题、文档标题、失效标记碰撞和恢复；代码／公式字面内容；自动链接；Unicode、查询参数、根路径和相对路径。
- `tests/main-markdown-link-maintenance.test.ts`：持久化更新、父子目录、事务与嵌套回滚、普通及 Wiki 入链、章节级联、断链分类、数据库迁移安全副本。
- `tests/main-markdown-file-interop.test.ts`：多文档、多附件、中文跨目录改名和移动，三轮真实文件导出再导入，删除原目录后继续读取附件，再从另一目录恢复备份并检查所有链接和块 ID。
- `e2e-tests/markdown-link-maintenance.spec.ts`：实际输入章节和文档标题、菜单移动、重载后跳转；断链检查前保存、键盘焦点循环、Escape 返回、来源展开定位、折叠状态下的完整文件导出。

## 使用边界

- 仅维护能确定身份的目标。同名文档歧义不会自动猜测；复杂源码块同时替换多个标题、且无法建立对应关系时，保留明确的失效目标。
- 普通 Markdown `#` 指向章节；Wiki `#` 后仍是块 ID。原始 HTML 自定义锚点不执行。
- 检查范围为当前完整文档的本地目标，不联网探测外部网址。未通过目录导入收纳的相对附件会提示，不推测磁盘来源。
- 单文件导出复制其使用的附件，不自动递归导出其他文档；整体迁移使用备份，或按相同目录结构导出相关文档。
- 当前证据说明本阶段的功能与往返一致性；长文档性能、异常输入、输入法及可复现竞品对照仍由第五阶段完成。
