# Markdown 真实文档与导入诊断

## 使用方式

在“总览”选择“导入 Markdown / 恢复备份”，选择目录并完成现有覆盖确认。导入成功后自动打开 Markdown 导入报告。

- 每个 Markdown 文档列出原文件路径、导入后的文档路径及新建／更新结果。
- 支持按文件名或文档路径搜索、只看需检查的文件；展开文件后可直接打开文档或定位到问题来源块。
- 报告检查本地文档、章节／自定义锚点、块引用与附件；区分找不到附件、目录外附件、无效路径及同名歧义。
- 报告提示未完整支持的 HTML、仅保留源码的 HTML 属性、未解析的外部 Wiki 别名和嵌入语法。代码、公式、普通 YAML、转义文本和图片替代文字不作为 HTML 或 Wiki 语法问题。
- 关闭报告后，可通过“查看最近导入报告”重新打开。报告保存于当前应用会话，反映导入时的检查结果；修改正文后请使用文档的“检查链接”重新检查链接。
- 报告最多列出每文件 100 项、整次导入 2000 项明细，其余数量明确显示；文件列表分页展示，不省略成功文件。外部网址不联网检查。
- 报告目前面向 Markdown 文档；独立数据库仍沿用恢复预检统计。不宣称识别所有第三方专有语法。

导入仍是整体事务：无效 UTF-8、目录边界、资源上限或恢复错误会中止导入；不把部分失败的结果显示成成功。覆盖确认、安全副本、数据库与附件回滚保持生效。报告在全部文档和附件恢复后生成，并在数据库事务中完成；生成失败同样回滚。

## 固定语料

目录：`tests/fixtures/markdown-real-documents/`。来源及许可见该目录 README；清单记录每个输入文件统一 LF 后的 SHA-256，测试过程不联网获取文件。

| 语料 | 文档数 | 预期诊断 | 验收重点 |
| --- | ---: | --- | --- |
| markdown-it 15.0.2 原始 README | 1 | 2 个未随 npm 包提供的文档 | 徽章、嵌套链接、引用式内容、提示块和代码 |
| KnowBook 实际高级语法文档 | 1 | 无 | 数学、脚注、表格、任务、Mermaid、目录及提示块 |
| 先前 Joplin 3.7.18 实测的真实 Markdown 导出 | 2 | 1 个原文件已有的过期 Wiki 目标 | `_resources`、原始跨段格式、代码字面链接和文件路径 |
| 先前 Typora 实测后保存的真实文件 | 2 | 2 个原文件已有的过期目标 | 原始表格、任务、普通链接、Wiki 和图片 |
| 本轮合成的多文件笔记库 | 2 | 8 项明确问题 | 中文空格路径、附件、YAML、折叠锚点、HTML 属性、别名／嵌入及缺失资源 |

两款编辑器样本直接固定此前实测留下的文件，不把本次文件回归称作新的竞品界面实测。既有失效链接按清单断言，不跳过，也不把它们算成新出现的导入缺陷。

每组都执行三轮普通文件导入／导出和三轮备份恢复，比较：

1. 与原始文档一致的渲染语义，保留结构与文本，仅将同一文档／同字节附件的不同存储地址统一后比较。
2. 原始代码、数学源码及 YAML；未支持的 HTML 和外部语法继续保留源码。
3. 真实附件字节、已解析文档／章节目标、导出稳定性和备份恢复后的块 ID。
4. 预期诊断分类和来源块定位；新建／更新状态、明细上限、取消、失败与重试。

## 本轮修复

- 原导入器会全文件扫描 `./__knowbook/assets/...`，把代码里的示例路径误当成必须存在的备份附件。现使用实际 Markdown 解析位置，仅对已识别的 KnowBook 备份文件头额外处理数据库等内部资源字段。
- 备份导出沿用相同范围：普通 YAML、行内代码、围栏和数学源码中的 `file:` 字面量保持不变；真实本地文件链接和备份数据库字段仍随附件迁移。
- 裸 `file:///…` 自动链接接入来源定位和资源复制；转为相对地址时生成有效 Markdown 链接，保留可见标签。
