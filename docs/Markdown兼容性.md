# Markdown 兼容性

KnowBook 的粘贴、Markdown 导入、阅读、表格预览和复制导出使用同一套 Markdown 解析规则，以 CommonMark 基础语法和常用 GFM 扩展为基线。

可将 [高级语法示例](examples/Markdown高级语法.md) 导入 KnowBook，体验脚注、公式、图表、提示块、高亮和文内目录。

## 支持范围

| 类别 | 支持内容 |
| --- | --- |
| 标题 | H1–H6，`#` 形式及 Setext 下划线形式；目录、章节折叠和聚焦支持全部六级 |
| 段落 | 空行分段、软换行、行尾两个空格或反斜杠产生的硬换行 |
| 行内样式 | `*` / `_` 强调、粗体、嵌套强调、`~文字~` / `~~文字~~` 删除线、`==高亮==`、字符转义、HTML 实体 |
| 代码 | 多反引号行内代码、反引号或波浪号围栏、缩进代码；保留语言及代码内空行 |
| 列表 | `-` / `*` / `+` 无序列表、`.` / `)` 有序列表、自定义起始编号、嵌套和多段落列表项 |
| 任务列表 | 有序与无序列表中的 `[ ]`、`[x]`、`[X]`，支持嵌套、混合普通列表项、多段落正文和保存勾选状态 |
| 引用和分隔线 | 多行与嵌套引用，`---` / `***` / `___` 分隔线 |
| 链接和图片 | 行内、引用式、自动链接；支持标题、转义和 URL 中的括号；定义可跨块使用 |
| 相对资源和跳转 | 导入相对图片及附件；相对 `.md` 文档链接、同页及跨文档章节锚点；支持中文、空格路径和 URL 编码 |
| 表格 | GFM 表格：可选首尾竖线、左/中/右对齐、空表体和空单元格、转义竖线、单元格行内样式/链接/图片、缺失单元格补齐、超出列数的单元格不显示；支持直接编辑单元格、行列增删、列对齐及电子表格粘贴 |
| 脚注 | `[^标记]` 与 `[^标记]: 正文`、行内 `^[正文]`、嵌套行内脚注、重复引用及逐处回链 |
| 数学公式 | `$…$`、`\(…\)` 行内公式；`$$…$$`、`\[…\]` 单行及多行块级公式，KaTeX 预览 |
| Mermaid | `mermaid` 围栏代码块，本地图表预览；支持流程图、时序图等随包提供的图表类型 |
| 提示块 | `> [!note] 标题` 等类型、带格式的标题、嵌套正文；`+` 默认展开、`-` 默认折叠 |
| 文内目录 | 独占一行的 `[TOC]`（大小写均可），列出正文标题，点击展开并定位章节 |
| KnowBook 扩展 | `[[文档或块引用]]` |
| YAML Front Matter | 文件开头的 YAML 键值文件头，原样保存字段、顺序、注释、嵌套数组、锚点/别名和多行标量；支持 `---` 或 `...` 结束标记 |
| 常用 HTML | `<br>`、`<kbd>`、`<sub>`、`<sup>`、`<details>/<summary>`、`<a>` 链接与自定义锚点、`<img>` 及整数宽高；折叠正文支持 Markdown、嵌套折叠、引用和列表 |

## 编辑与往返规则

- 逐字输入标题、列表或引用的标记后，输入空格才转换块类型。代码、公式和表格源码编辑器保留原始输入。
- 粘贴普通多行文本保留段内换行；空行分段或结构化 Markdown 按统一语法转换。代码块内的粘贴不会转换成标题、列表等其他块。
- 简单嵌套列表转为可操作的块层级，最多六层缩进。复杂列表项或更深层内容以 Markdown 保留在列表项内部，并在阅读时渲染。
- 复制与普通 Markdown 导出保留列表标记、紧凑／松散状态及相邻列表边界，其余缩进和部分空行会规范化；不承诺逐字节保留原文件格式。编号重启通过切换有序列表分隔符保留。多行 Setext 标题、Tab 缩进代码、空围栏和原始围栏信息均保留语义。
- KnowBook 备份另外包含块元数据，用于恢复块 ID、块类型、父子关系、标签、高亮、编号起点、列表格式和代码围栏信息。数据库版本 14 增加格式信息字段，并沿用迁移前安全备份机制。
- YAML 文件头作为独立源码块保存；阅读时可展开“文档属性（YAML）”。粘贴、源码编辑、撤销重做、保存重载和备份均保留内容，行尾统一为 LF。普通导出把文件头放在自动生成的文档标题之前；普通文件的 `id`、`path`、`kind`、`summary` 等属性不会改写应用内文档身份或触发数据库恢复。
- 新备份在内部文件头后加入 `<!-- knowbook:backup v1 -->`；旧备份按完整字段结构或 KnowBook 块元数据识别，旧数据库清单同时要求其保留路径。普通 YAML 不被重新格式化，也不参与链接和图片收纳。
- HTML 的原始标签与属性保留在源码和 Markdown 导出中。预览只生成允许的元素与属性；图片及链接使用既有附件收纳、路径维护和跳转流程。自定义锚点使用 `<a id="标记"></a>` 或 `<a name="标记"></a>`，从 `#标记` 跳转时会展开所在折叠内容。
- 数据库版本 18 重建既有文档的 HTML 链接索引，使升级后尚未编辑的文档也能参与出入链和改名维护；升级前保留安全副本，不改写原有正文。
- 引用式链接的定义保留为可编辑源码块。修改定义后，阅读正文、表格和媒体预览同步解析。
- 正文、表格、提示块和脚注共用整篇文档的解析结果。脚注定义保留为源码，阅读时集中显示在文末；未引用的定义不产生额外脚注。移动定义不会改变编号，重复引用显示同一编号，每处引用均有单独回链；回跳会展开对应章节和提示块。
- 高亮、行内公式、脚注、提示块和目录在源码下方显示编辑预览。提示块中的图片保留在提示块内部，随正文一起折叠。公式和 Mermaid 出错时保留源码并显示错误，修正源码后更新预览。
- 表格默认显示可操作的单元格，点击或按 Enter / F2 编辑；源码可展开编辑，两者同步。Tab / Shift+Tab 切换单元格，末格 Tab 新增行；Enter / Shift+Enter 向下／向上移动，Esc 返回单元格后可用 Tab 离开表格。粘贴电子表格的多行多列内容会自动扩展表格，支持带引号的字段；字段内的换行和制表符用字符实体保留。
- 表格单元格中的竖线自动转义，既有行内格式、引用定义和未显示的多余单元格会保留。表头不可删除，最后一列不可删除，以保持有效的 GFM 表格；表体可以全部删除。
- 普通文本选区和表格单元格提供粗体、斜体、删除线、高亮、行内代码和链接操作。快捷键分别为 Ctrl/⌘+B、I、Shift+X、Shift+H、E、Shift+K；Ctrl/⌘+K 继续用于全局搜索。Alt+F10 进入格式工具栏，方向键切换按钮，Esc 返回编辑区并保留选区；普通文本也可用 Shift+Tab 进入工具栏，列表保留 Shift+Tab 减少缩进。输入法候选操作不会触发格式或表格导航。
- `/table`、`/mermaid`、`/callout`、`/toc` 可插入表格、图表、提示块和目录模板。命令须出现在行首，精确命令优先匹配；当前块还有其他文字时保留文字，并在其下方插入模板。
- 数学块导出统一使用多行 `$$`，表达式保留；行内数学、脚注、高亮、提示块和 Mermaid 内容保留其 Markdown 源码。脚注中的图片与附件也参与文件导入和导出收纳。
- 编号待办可通过 `3. [ ] ` 或 `/numbered-todo` 创建，编号与普通有序列表项连续；按 Enter 继续创建未勾选的编号待办。简单任务以及复杂列表、引用、提示块、脚注中的任务，均可在预览和阅读模式勾选，并保存到对应的原始标记。
- 表格结构操作、格式操作和任务勾选接入文档撤销与自动保存；阅读模式可撤销和重做本次阅读中的任务操作，不会越过模式切换点修改此前的源码编辑。阅读列表按完整文档的解析结果分组，保留列表边界、起始编号、嵌套和紧凑／松散间距，折叠后不会丢失内部内容。
- 任务标记仅在列表项的首段开头生效。`\[x]`、实体编码的方括号、行内代码和 `[x]无空格` 均保留为文字。三条及以上连续波浪号不产生行内删除线。
- 普通 Markdown 导入时，跳过 YAML 文件头后，若首个一级标题与文件名一致，该标题作为文档标题使用，避免单文档反复导入导出累积重复标题；其他正文标题及 KnowBook 备份保持原样。
- 导入相对图片和附件时，以 Markdown 文件所在目录解析 `./`、`../`；`/` 从所选导入目录解析。实际文件需位于所选目录内，导入后复制到应用管理的附件目录，因此移动或删除原文件夹不会使图片失效。缺失文件保留原始链接。
- 单文件导出会将使用到的托管图片和附件复制到同级的 `文件名.assets/`，并写成相对链接；迁移时需要一起携带该文件夹。备份则沿用统一附件目录。
- 相对文档链接按文档树对应的文件路径解析，例如 `Docs/Start` 中的 `[下一章](Next.md#安装)` 指向 `Docs/Next`；`../Guide.md` 指向上一级，`/Guide.md` 指向工作区根目录。导入和备份会转换文件名与文档元数据路径之间的对应关系。
- 章节锚点使用标题的可见文字生成：转为小写，移除标点，空格变为 `-`，同名标题依次使用 `-1`、`-2` 等后缀；保留中文。文档标题也可作为返回顶部的锚点。规则参考 [GitHub 章节链接说明](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#section-links)。
- 编辑模式中的链接预览、阅读正文、表格内链接共用跳转逻辑。跳转会等待目标文档加载，使用当前正文解析锚点，并展开遮挡目标的折叠章节。找不到文档或章节时显示提示。
- 文档改名或跨目录移动时，自动维护普通 Markdown 文档链接、引用式定义及已明确解析的 Wiki 文档／跨文档块引用；同时重算移动文档中的相对出链。根路径、查询参数和链接标题保持原有含义，代码和公式中的字面文本不参与修改。普通 Markdown 文档链接也计入出链和反向链接。
- 章节改名和同名章节次序变化按稳定块 ID 维护锚点。删除章节时，原链接改为携带原章节身份的失效标记，避免误跳到另一同名章节；恢复原块可恢复链接。包含多个标题的复杂源码块只在能确定对应关系时维护，无法确定时保留为失效目标。
- 文档“更多”菜单中的“检查链接”先保存当前草稿，再检查完整文档中的本地文档、章节、块引用和附件；结果可展开折叠区并定位到来源块。外部网址不联网检查。粘贴的相对附件尚未收纳、失效路径和同名文档歧义会分别提示。
- 数据库版本 15 增加可重建的 Markdown 来源索引，与正文修改在同一事务内更新，并保留升级前安全副本。批量恢复以导入内容为准；未被覆盖的文档引用按恢复前后的最终路径维护，不跟随恢复过程中的临时路径重复改写。
- 版本 17 按解析器实际识别的位置统一来源索引、出入链关系，并保留升级前安全副本。表格单元格中的未闭合公式或代码不会遮住相邻单元格的链接；多余列、图片替代文字、公式及代码中的字面内容不会被误改或计入文档关系。普通链接标签内的 Wiki 和自动链接显示为文字，避免嵌套跳转。Wiki 路径及唯一标题解析保留大小写不敏感行为。
- `<file:…>` 形式的托管附件也会随单文件导出收纳；相对地址导出为普通 Markdown 链接。复制与文件导出始终包含完整草稿，不受章节折叠或聚焦范围影响。

## 边界

目录导入现提供逐文件兼容性报告，支持搜索、筛选及来源块定位。真实 README、技术文档、已有编辑器导出文件和多文件笔记库的往返验收见 [导入诊断验收](Markdown导入诊断验收.md)。

- HTML 支持上述常用子集，未知或不完整的标签保留为文字；不支持任意 HTML/CSS 布局、脚本、事件属性、iframe、SVG 或危险 URL。允许链接/图片地址、替代文字、标题、自定义锚点、展开状态和 1–10000 的整数宽高。外部链接打开支持 HTTP、HTTPS、邮件，以及应用管理的附件目录内的本地文件。
- YAML 文件头须位于文首、具有结束分隔符及顶层键值字段；普通 `---` 分隔线保持原语义。此阶段保留 YAML 源码，不提供字段类型编辑器或 YAML 校验，不会执行 YAML 自定义标签或解析别名。
- 相对图片的收纳发生在文件导入时；仅粘贴 Markdown 文本无法得知原文件所在目录。跨文件跳转目前面向 `.md` 文档；单文件导出不自动导出它链接到的其他文档，整体迁移请使用备份或保持文档目录结构。
- 自动维护面向工作区内可确定身份的链接，不猜测同名文档或恢复时无法匹配的复杂章节。Wiki 的 `#` 后仍是块 ID；普通 Markdown 的 `#` 后是章节或 HTML 自定义锚点。
- 数学公式采用 KaTeX 支持的 TeX 子集，关闭可信 HTML 扩展并限制宏展开；`$5 and $10` 等常见价格文字不会识别成公式。不把未闭合分隔符自动补齐，原文仍可编辑。
- Mermaid 按需加载本地代码，图表内容不能开启 HTML 或点击回调。图表内外部图片暂不支持，保留源码并显示提示；单图限制为 50000 字符、500 条边。Markdown 导出保留图表源码，不将 SVG 写回正文。
- 提示块支持 `[!类型]` 与 `+` / `-` 的常见形式，未知类型使用通用外观；不承诺实现其他应用的所有专有扩展。文内目录不包含脚注正文中的标题。
- 已接入 CommonMark 0.31.2 的 652 条及 GFM 0.29-gfm 的 677 条官方样本，验证三轮普通 Markdown／元数据备份往返和 SQLite 持久化。仍有明确的产品差异，不宣称完全兼容；逐项统计、边界与复现命令见 [规范验证报告](Markdown规范验证报告.md)。
- “完整表格”按 [GFM 表格规范](https://github.github.com/gfm/#tables-extension-)定义：单元格支持行内内容；合并单元格、跨行单元格和单元格内块级元素不属于 GFM 表格语法。
