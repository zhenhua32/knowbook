# KnowBook 管理页面设计规范

> 版本：1.0  
> 适用范围：总览、数据库、AI 助手、插件中心、配置中心，以及这些页面共用的导航和管理型弹窗。  
> 不适用范围：文档阅读、编辑、文档树和文档辅助面板。文档工作区继续按内容创作场景独立演进。

## 1. 设计目标

KnowBook 的管理页面应当像同一套产品，而不是多个功能模块的拼接。所有管理页面遵循以下原则：

1. **可读优先**：以配置中心当前的阅读尺度为基准。100% 系统缩放下，正文不小于 14px，任何承载信息的文字不小于 12px。
2. **层级稳定**：相同语义使用相同字号、字重、颜色和间距。页面标题、区块标题、字段标签不能因页面不同而改变尺度。
3. **适度密度**：普通页面使用舒适密度；只有数据库表格、筛选工具栏等高信息密度区域允许使用紧凑控件。
4. **操作明确**：主操作、次操作、危险操作和状态展示必须有稳定的视觉语义；一个操作区最多一个主按钮。
5. **渐进披露**：路径、哈希、调试信息和开发者选项默认弱化或收起，避免与日常管理任务争夺注意力。
6. **响应式而非缩小**：空间不足时调整列数和布局，不通过继续缩小字号维持桌面布局。

## 2. 基础设计令牌

### 2.1 字体

```css
--kb-font-sans: "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
--kb-font-mono: "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

管理页面只使用无衬线字体。代码、路径、插件 ID、revision 和哈希使用等宽字体。

### 2.2 字号与行高

| 令牌 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display` | `32px / 40px` | 750 | 页面主标题；小屏可降至 28px |
| `title-lg` | `20px / 28px` | 700 | 一级内容区、弹窗标题 |
| `title-md` | `16px / 24px` | 700 | 卡片、列表项目、检查器标题 |
| `body` | `14px / 22px` | 400 | 正文、描述、表单内容 |
| `body-strong` | `14px / 22px` | 600 | 导航、按钮、重要正文 |
| `label` | `13px / 20px` | 600 | 字段标签、筛选项、数据标签 |
| `caption` | `12px / 18px` | 400 | 辅助说明、元数据、时间、路径 |
| `caption-strong` | `12px / 18px` | 650 | 状态、徽标、眉题 |
| `metric` | `30px / 36px` | 700 | 概览统计数字 |

硬性约束：

- 管理页面不得出现小于 12px 的信息文字。
- 状态点、装饰图形可以小于 12px，但其相邻文本仍须至少 12px。
- 中文正文默认行高不低于 1.55；长说明建议 1.6。
- 不使用全大写英文作为中文页面的主要层级手段。眉题可使用字距，但必须保持 12px。

### 2.3 间距

采用 4px 基础网格：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。

- 页面外边距：桌面 `28px 32px 48px`；中屏 `24px`；窄屏 `16px`。
- 页面区块间距：`20px`。
- 面板内边距：常规 `24px`，紧凑 `20px`。
- 卡片内边距：`16px` 或 `20px`。
- 表单字段间距：`16px`；标签与控件间距 `8px`。
- 同组按钮间距：`8px`；不同操作组间距 `16px`。

### 2.4 尺寸

| 元素 | 常规 | 紧凑（仅高密度区域） |
| --- | --- | --- |
| 输入框 / 下拉框 | 42px | 36px |
| 文本按钮 | 40px | 36px |
| 图标按钮 | 40 × 40px | 36 × 36px |
| 搜索框 | 42px | 36px |
| 列表行 | 最低 68px | 最低 56px |
| 开关 | 36 × 20px | 不再缩小 |

所有可点击区域不得小于 36 × 36px。危险操作不能仅靠颜色区分。

### 2.5 颜色与表面

沿用 KnowBook 当前冷灰 + 靛蓝体系：

```css
--kb-bg: #f3f5f9;
--kb-canvas: #ffffff;
--kb-text: #1a2030;
--kb-text-soft: #596174;
--kb-text-muted: #667085;
--kb-line: #e6e9f0;
--kb-line-strong: #d9dee8;
--kb-accent: #5b63e8;
--kb-accent-strong: #444bc7;
--kb-accent-soft: #eef0ff;
--kb-success: #25805f;
--kb-warning: #a56516;
--kb-danger: #b52f47;
```

- 页面背景使用 `--kb-bg`，主要工作面使用白色。
- 次要文本优先使用 `--kb-text-soft`；`--kb-text-muted` 只用于辅助信息。
- 正常面板边框为 `--kb-line`，交互控件边框为 `--kb-line-strong`。
- 阴影只表达层级，不作为分隔线替代：常规面板 `0 10px 30px rgba(34, 42, 61, .055)`。
- 成功、警告、危险状态同时使用文字或图标，不单独依赖红绿颜色。

### 2.6 圆角

- 小元素、徽标：`8px`。
- 输入框、按钮、普通卡片：`10–12px`。
- 主面板：`16–18px`。
- 页面 Hero：`22px`。
- 胶囊形只用于状态、筛选和短标签，不用于大面积普通按钮。

## 3. 页面骨架

管理页面统一为以下结构：

1. **页面标题区**：眉题、32px 主标题、14px 描述、右侧页面级操作。
2. **概览区（可选）**：2–4 个统计卡片；标签 13px，数值 30px，说明 12px。
3. **任务区**：以面板承载主要列表、表格、对话或表单。
4. **辅助区（可选）**：桌面位于右侧，宽度 320–380px；中屏下移为整行。
5. **开发者信息（可选）**：默认折叠，包含路径、哈希、revision、插件根目录等信息。

主内容最大宽度为 `1520px` 并居中。数据库工作台可放宽至 `1760px`。普通页面不应把单行文字拉伸超过约 80 个中文字符。

## 4. 组件规范

### 4.1 导航

- 一级导航文字：14px / 20px，字重 600。
- 图标：18px；图标与文字间距 10px。
- 导航项最低高度 40px，圆角 10px。
- 激活项使用浅色背景、清晰文字和轻量描边；不依赖粗重外发光。
- 折叠态仍保留 40 × 40px 命中区域和可读的提示文本。

### 4.2 按钮

- 主按钮：品牌色实底；每个操作区最多一个。
- 次按钮：白底描边。
- 危险按钮：浅红底或红色文字，并显示明确动词，例如“卸载插件”。
- 按钮文字统一 14px / 20px、字重 600。
- 加载态保持按钮宽度，禁用态仍需满足文字对比度。

### 4.3 表单

- 标签置于控件上方，13px / 20px、字重 600。
- 控件内容 14px；辅助说明和校验信息 12px / 18px。
- 相互关联的开关使用分组卡片，不将所有开关堆成无层级列表。
- 保存操作靠近所属表单；避免跨越整页的全宽按钮串。
- 只读路径、令牌、端点使用可复制控件，并允许换行或水平滚动。

### 4.4 列表、卡片与表格

- 列表主标题 14–16px；描述 14px；元数据 12px。
- 普通列表行最低 68px，行内操作在悬停、聚焦或选中时清晰出现。
- 表格单元格正文 13px，表头 13px / 600，次要信息 12px。
- 选中态使用浅品牌色背景 + 左侧 3px 标识或清晰描边。
- 空状态标题 16px，说明 14px，提供一个明确下一步。

### 4.5 状态、徽标和开关

- 徽标文字 12px / 18px、字重 650，横向内边距至少 8px。
- 状态命名使用用户语言，例如“运行中”“已停用”“需处理”，避免直接暴露内部枚举。
- 开关只表达即时启用/停用；卸载、删除、恢复等动作必须使用按钮并确认。

### 4.6 对话与侧栏

- 对话正文 14px / 22px；系统事件和工具事件不低于 12px / 18px。
- 对话输入区固定在任务区底部时，输入文字仍为 14px。
- 检查器或定制侧栏宽 360–720px，标题 20px，正文 14px。
- 侧栏在窄屏占满宽度，不通过缩小字号保留双栏。

## 5. 各页面应用规则

### 总览

- 使用标准页面标题区、四列指标和事件任务区。
- 存储状态、最近文档与备份操作使用相同卡片标题和正文字号。
- 总览只显示摘要；详细配置留在配置中心。

### 数据库

- 页面标题、数据源说明和全局操作使用常规密度。
- 表格、筛选、视图切换允许紧凑高度 36px，但正文仍为 13px、辅助信息仍为 12px。
- 卡片视图、看板视图与抽屉统一标题和元数据层级。

### AI 助手

- 会话工作台是主任务区，普通文档问答为次任务区。
- 会话文本 14px，工具事件 12px，输入控件 42px 以上。
- 会话、审批和错误状态使用统一的成功 / 警告 / 危险语义。

### 插件中心

- 保留“页面标题—统计—插件列表—检查器—开发者信息”的层级。
- 插件名 16px，描述 14px，版本 / 来源 / ID 12px，任何状态徽标不低于 12px。
- 生命周期步骤标题 13px，步骤说明 12px。
- AI 定制使用独立侧栏，沿用 AI 助手的对话字号。

### 配置中心

- 作为管理页面可读尺度的基准。
- 设置按“基础 / AI / 网页剪藏 / 更新 / 备份”分组，不使用连续全宽按钮堆叠。
- 字段标签 13px，输入文字与开关说明 14px，帮助文本 12px。

## 6. 响应式规则

- `> 1280px`：完整多列布局。
- `769–1280px`：减少页面边距；四列指标变两列；辅助栏缩至 320px 或下移。
- `<= 768px`：单列；页面操作换行；辅助栏 / 对话侧栏占满宽度。
- `<= 520px`：页面边距 16px；指标仍可两列，但内容不得溢出。

任何断点下，字号不得因适配而低于本规范下限。

## 7. 无障碍与交互反馈

- 文本与背景对比度满足 WCAG AA；正文目标至少 4.5:1。
- 所有键盘可操作元素必须具有清晰的 `:focus-visible` 样式。
- 状态变化应有文字反馈；运行中、保存中、失败和完成不能只使用动画表达。
- 尊重 `prefers-reduced-motion`，关闭非必要位移和淡入动画。
- 表单错误与对应字段建立语义关系；弹窗和侧栏需提供标题、关闭按钮与焦点管理。

## 8. 验收清单

- [ ] 管理页不存在小于 12px 的信息文字。
- [ ] 页面标题、区块标题、卡片标题、正文、标签、辅助文字均映射到统一令牌。
- [ ] 常规输入框和按钮高度分别达到 42px / 40px；紧凑控件只出现在高密度区域。
- [ ] 总览、数据库、AI、插件、配置中心在同一窗口尺寸下具有一致阅读尺度。
- [ ] 插件状态、生命周期和危险操作在无需猜测的情况下可理解。
- [ ] 1280px、1024px 和 768px 宽度下不通过缩小字号维持布局。
- [ ] 文档阅读和编辑区域的字号、密度未被管理页面规范影响。
- [ ] 浅色和深色主题均通过视觉检查；键盘焦点可见。
