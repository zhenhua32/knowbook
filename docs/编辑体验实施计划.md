### 块菜单与格式阶段

两种编辑模式共用单块／多块动作，支持完整类型转换、复制稳定块链接、复制／删除子树和选择目标文档移动。仅显式选中的块改变类型，折叠子块保留自身类型；移动携带完整连续同级子树，保留块 ID、完成状态、标签、列表格式及原创建时间。移动、成对撤销／重做、引用重写与两侧历史在同一事务中提交。重启后仅当所有参与文档的内容与路径仍一致时恢复该移动的撤销入口，后续编辑不会被覆盖。

块链接使用 Markdown 路径与 `#^块ID`；旧路径可定位到移动后的归属文档；文档或祖先改名、移动时，在路径事务中保存旧路由，并验证重启后仍可达。同步接收端也在远端路径改写前保存实际见过的路径与原块 ID，排除刚移入的块，避免虚构旧目标路径。明确缺失的块不会错误回退到同名标题。目标文档加载、菜单按需加载及异步回复均核验当前会话，离开窗口或转移注意力后不会自动夺回焦点。源码及富文本均支持下划线和九种有限文字／背景色，颜色可独立清除，中文组合输入与反向选区保持原有行为。

WebDAV 接收会在发布清单前核验批次整体归属，再在数据库事务中重复核验；移动身份先改归属，再处理来源释放／删除，避免接收顺序造成主键冲突或丢块。来源或目标出现冲突时阻止部分移动，保存可重启恢复的冲突报告，选择远端或独立副本后可重试。拟发布清单也整体核验块归属；移动双方均有冲突而只处理一方时，拒绝发布重复身份或丢块的清单，知识、同步基线与最后同步时间保持不变，完整处理双方后仍可重试。

### 页面编排：分栏实现范围（6a）

源码、富文本和阅读均以实际并排内容展示分栏。每组包含一至六列，列可为空，也可包含段落、标题、列表、表格、媒体和混合容器；嵌套继续遵守六层上限。富文本使用同一个编辑器与文档历史，跨列文字选区、剪切、替换、组合输入和表格操作保持结构身份。结构控件支持增删列、拖排、整棵内容子树跨列移动、取消分栏及显式添加正文；删除列和取消分栏保留正文。空列不自动持久化占位段落。

列比例以绑定列 ID 的整数基点保存，同组总和固定为 10000。相邻拖动只预览，松开提交一次；Esc、取消、失焦、来源更新和会话切换放弃预览。纯列宽修改参与脏状态与历史比较。不同列的并发正文可自动合并，整组比例并发修改须显式选择其中一个完整版本；不会按列合成第三组比例。完整分栏可跨文档移动，原 ID、创建时间、旧链接路由及成对撤销继续由原事务处理；缺失结构壳的局部移动在写入前拒绝。

普通 Markdown 使用有限 `columns-v1`／`column-v1` 标记和显式权重，不含原块 ID；备份保留身份、归属、注释和比例。非法角色、列数、比例、带空白结构类型及矛盾的备份元数据在应用前拒绝。未标记 HTML、行内代码和代码围栏中的示例保持字面语义，不触发分栏协议升级；合法结构与另一处损坏标记混存也会被同步验证拒绝。
