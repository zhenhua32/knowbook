## 🚀 如何运行

### 单元测试
```bash
npm test
```

### E2E 测试
```bash
# 安装浏览器
npx playwright install chromium

# 终端1：启动开发服务器
npm run dev

# 终端2：运行测试
npx playwright test

# 或运行特定测试
npx playwright test e2e-tests/document-crud.spec.ts
```
