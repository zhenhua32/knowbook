## KnowBook 0.2.0

### 主要更新

- Markdown 编辑与阅读：支持全文源码编辑，改进表格、公式、脚注、引用和高级语法展示，提升导入、导出及备份恢复时的格式保真度。
- 长文档体验：新增阅读模式、章节折叠和专注浏览；全文源码编辑采用虚拟化，优化输入响应、选区同步、撤销重做及中文输入法体验。
- 文档链接：改进 Wiki 链接、块引用和文件互操作诊断，重命名与移动文档时更准确地维护引用。
- Database 工作台：支持表格、看板和卡片视图，完善组合筛选、多字段排序、分组、保存视图和批量编辑。
- 插件系统：提供隔离的 v2 动态插件与 Full Trust v3 系统插件，完善安装、依赖、后台服务、故障恢复和插件中心。
- 内置主题：提供云白、暖纸、青苔、海湾、午夜、紫夜六款配色，支持即时切换和保存偏好。
- 网页剪藏与 AI：改进应用内及浏览器扩展剪藏、文档问答和选区改写，并持续优化界面与运行性能。

### 升级说明

- v1 插件系统已移除。旧插件文件和历史设置保留，但不再自动加载；自定义插件需迁移到 v3 后重新安装。
- 相关笔记使用本地关键词检索，不再提供 Embedding、向量数据库或后台向量回填。
- 本次包含数据库结构升级，建议升级前备份本地数据。插件开发与恢复说明见仓库 `docs/` 目录。
