## KnowBook 0.3.0

### 主要更新

- 正文编辑默认使用连续富文本，支持跨段选择、格式化和撤销重做，也可切换到全文 Markdown 源码。改进网页和 Word 富文本粘贴、表格编辑，以及图片的尺寸、裁剪、图注和对齐。
- 页面支持可调宽分栏、文内数据库视图、提示块和折叠块。同步块可以在同一工作区的多处复用正文，编辑一处会更新其他引用。复制或导出 Markdown 时，每处引用都会展开为可独立编辑的正文。
- 个人 WebDAV 同步覆盖文档、同步块、数据库和附件，支持加入已有目录、处理离线冲突和传播删除记录。
- 数据恢复支持回收站、文档历史和版本化备份。完整 V3 备份保留同步块及相关工作区状态，改进大备份的恢复，并支持恢复后续接原 WebDAV 目录。
- 新增文档模板、快速记录和内置文档翻译插件，改进全文搜索、Wiki 链接和 Markdown 导入诊断。

### 升级说明

- 本机数据库升级到版本 27。应用在升级前会创建安全副本，升级前也可另存一份独立备份。旧版 KnowBook 无法打开升级后的数据库或读取完整 V3 备份。
- WebDAV 统一使用协议 5，请将所有同步端升级到兼容版本。若仍在使用协议 1–4 的远端目录，可保留原目录，在新的空目录重新发布本机工作区。
