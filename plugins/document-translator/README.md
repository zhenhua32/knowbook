# 文档翻译（System Plugin v3）

KnowBook 内置的 v3 插件，随应用提供并默认启用，无需单独安装。使用 KnowBook 已配置的 AI 服务，将已保存文档翻译成简体中文，或生成逐块双语对照。插件 ID 为 `document-translator`。

## 使用

1. 启动 KnowBook，在设置中启用 AI，填写 OpenAI-compatible 接口地址、模型和 API Key。
2. 打开文档并保存编辑，点击右上角“…”更多操作，在“文档翻译”分组中选择“翻译成中文”或“生成双语对照”。点击后会将待译内容发送到所配置的 AI 服务。
3. 点击后菜单自动关闭，右下角的应用内通知显示翻译进度，并可取消任务。完成后点击通知中的“打开译文”，也可在文档树的原文同级目录打开新文档。
4. 在插件中心可查看“来源：内置”及运行状态，或停用插件；重新启用后按提示重启应用。

默认启用只注册翻译入口；AI 未配置时按钮不可用。翻译仅在点击操作后发起。

代码由 `src/main/system-plugin/builtin-catalog.ts` 编译进主进程包，无需 npm 依赖或后台服务。修改源码后重新构建并启动应用，宿主按内容哈希更新内置版本。已有手动安装会迁移到内置代码，并保留停用和安全停用状态；安全模式不加载插件。

内置插件随应用更新，不能单独安装、替换、卸载或回滚。无需导入旧版单独分发的 ZIP；普通外部 v3 插件仍需确认精确安装内容，manifest 无法将插件声明为内置。

## 两种模式

- **翻译成中文**：翻译标题、摘要和正文，以“译后标题（中文）”保存副本。
- **双语对照**：以“原标题（双语对照）”保存。普通内容块和表格按照原文、译文依次排列；标题在同一行显示原文和中文。列表及待办在同一条目中先显示原文，再显示译文，保留编号、勾选状态及嵌套关系。相同内容只保留一次。

代码块（含 Mermaid）、公式块、YAML 元数据、分隔线及未知块类型原样复制。行内代码、公式、完整链接及其标签、图片、Wiki 引用、引用定义和 HTML 标签通过占位符原样保留，表格保留分隔符和换行。块标签、高亮和列表元数据保留，副本使用新的块 ID；原有块引用仍指向原文。

结果与原文位于同一目录，以保持相对文档链接的基准；指向本文标题的 `#锚点` 可能因标题翻译而需要手动调整。原文和已有译文均不覆盖，重名由宿主自动处理。只翻译当前文档，不递归翻译子文档。

## 进度与失败处理

长文档自动分批，单次 AI 输入的待译文本最多约 6000 字符，单段最多约 3000 字符；超长段落会拆分后合并。每批 120 秒超时，文档上限为 50 万字符。实际费用、上下文容量及翻译质量取决于配置的模型。

同一时间执行一个翻译任务。关闭菜单、切换文档或页面后任务继续，右下角通知持续显示进度；点击通知中的“取消翻译”或停用插件会取消未完成请求。全部译文验证通过后才创建文档，保存阶段不再接受取消。完成和失败通知保留到手动关闭，通知内可直接打开译文，更多菜单只保留翻译入口。失败、取消或原文在翻译期间被编辑/删除时，不保存部分译文。失败后可重新开始，已经成功的 AI 请求仍可能计费。

任务进度只保存在内存，退出应用后不恢复；已经生成的知识库文档在重启或停用插件后仍保留。Renderer 仅查询状态及发起/取消任务，不接收 API Key；Main 使用宿主 `ai.complete` 和 `documents` API。

## 开发验证

在仓库根目录运行：

```sh
npm run typecheck:system-plugin-examples
npm run typecheck
npm run test
npm run build
npx playwright test e2e-tests/document-translator.spec.ts --grep '@electron'
```

测试覆盖真实 Store 与 v3 生命周期、两种输出模式、长文档分批、格式保护、模型异常、取消和界面交互。Electron 用例验证内置插件首次启动自动启用、无需安装确认、停用保留和重新启用。测试中的 AI 使用本地模拟响应，不调用外部服务。
