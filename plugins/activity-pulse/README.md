# Activity Pulse（System Plugin v3）

仓库自带的文档活动插件，插件 ID 保持为 `activity-pulse`。新版只使用 System Plugin v3 的 Main 和 Renderer 入口。

## 安装

1. 在 KnowBook 插件中心选择“安装系统插件”，选中本目录。
2. 检查插件 ID、版本、SHA-256 和完整访问声明，勾选风险确认并输入 `activity-pulse`，点击“确认系统安装”。
3. 重启 KnowBook，插件进入运行状态后，首页显示 Activity Pulse 卡片。

目录中的代码不会因存在于 `plugins/` 就自动执行。此前安装或启用旧版不代表已授予完整访问权限，必须重新完成系统插件确认流程。停用会立即清理界面、事件订阅和操作接口；安装、启用、更新等操作按系统插件中心的“需要重启”提示生效。

首次确认并启动新版时，会自动保留此前保存的摘要前缀。已有新版配置不会被旧值覆盖；文档及摘要保持原样，直到用户执行摘要操作。

## 功能

- 首页卡片显示最近观察到的文档创建、保存事件。
- 文档操作“从首个内容块生成摘要”读取已保存文档的第一个非空内容块，将连续空白压缩为空格并截取前 80 个字符，然后保存摘要。
- 设置页的 Activity Pulse 区域可保存摘要前缀；空白前缀不会被添加。前缀原样连接到摘要内容，需空格时请自行在前缀末尾添加。
- 没有非空内容块时保留原摘要并显示提示。

Main 入口负责文档事件、摘要操作和持久化设置，Renderer 入口通过系统插件 API 注册首页卡片、文档操作和设置区域。无需 npm 依赖、构建步骤或后台服务。
