# KnowBook Web Clipper

这是一个 Manifest V3 浏览器扩展，用来把当前页面发送到本机 KnowBook。桌面端桥接服务只监听 `127.0.0.1`，并使用 Bearer token 鉴权。

## 使用方式

1. 在 KnowBook 的 **配置中心 → 网页剪藏** 中点击 **导出浏览器扩展**，选择一个父文件夹。应用会新建 `KnowBook Web Clipper` 子目录；导出后可点击 **打开导出目录** 查看完整安装文件。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，启用 **开发者模式**，选择 **加载已解压的扩展**，指向导出的 `KnowBook Web Clipper` 目录。若正在阅读导出目录中的本说明，选择本文件所在目录即可；该目录根级应有 `manifest.json`。
3. 回到 KnowBook，勾选 **启用本地网页剪藏桥接服务** 并保存，复制 **扩展提交地址** 和 **授权令牌**。令牌默认隐藏，复制按钮会复制完整值。
4. 点击浏览器扩展图标，在弹窗中填写提交地址与 Bearer Token，点击 **保存配置**。
5. 打开任意 `http` / `https` 页面，点击扩展图标执行 **剪藏当前页**。

默认提交地址是 `http://127.0.0.1:3210/clip`。如果在 KnowBook 中修改端口或重置令牌，需要同步更新扩展配置。令牌等同本机写入凭据，不要公开分享。

## 安装文件与重新导出

KnowBook 安装版随附此扩展，导出不需要联网，也不需要下载仓库源码。导出目录只包含以下五个文件：

- `manifest.json`
- `popup.html`
- `popup.js`
- `page-collector.js`
- `README.md`

这些文件不包含本机授权令牌、端口配置或个人数据。提交地址和令牌由你在扩展弹窗中配置。

取消文件夹选择不会写入文件。所选父文件夹中已有 `KnowBook Web Clipper` 时，应用会拒绝覆盖，包括已有的空目录；请另选父文件夹。导出失败或打开目录失败后，最近成功导出的目录仍会保留，可重试打开。更新 KnowBook 后可重新导出当前随附版本，再到浏览器的扩展管理页重新加载新目录。

## 当前能力

- 发送当前页面完整 HTML、正文纯文本和常见元数据
- 支持手动覆盖标题
- 支持附加一段仅本次导入的备注
- 与桌面端重复检测联动，重复内容会直接复用已有文档

## 已知限制

- 目前固定导入到文档根级，不支持从扩展里选择父文档
- 本机桥接请求上限为 4 MiB，特别大的页面会被拒绝
- 仅在 Chromium/Edge 的 MV3 环境下验证过
