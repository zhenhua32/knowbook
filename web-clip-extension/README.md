# KnowBook Web Clipper

这是一个 Manifest V3 浏览器扩展，用来把当前页面发送到本机 KnowBook。桌面端桥接服务只监听 `127.0.0.1`，并使用 Bearer token 鉴权。

## 使用方式

1. 在 KnowBook 设置页启用“浏览器桥接”。
2. 复制“扩展提交地址”和“授权令牌”。
3. 在 Chromium/Edge 的扩展管理页打开“开发者模式”。
4. 选择“加载已解压的扩展”，指向当前目录。
5. 打开任意 http/https 页面，点击扩展图标，填入地址和令牌后执行剪藏。

默认提交地址是 `http://127.0.0.1:3210/clip`。如果在 KnowBook 中修改端口或重置令牌，需要同步更新扩展配置。令牌等同本机写入凭据，不要公开分享。

## 当前能力

- 发送当前页面完整 HTML、正文纯文本和常见元数据
- 支持手动覆盖标题
- 支持附加一段仅本次导入的备注
- 与桌面端重复检测联动，重复内容会直接复用已有文档

## 已知限制

- 目前固定导入到文档根级，不支持从扩展里选择父文档
- 本机桥接请求上限为 4 MiB，特别大的页面会被拒绝
- 仅在 Chromium/Edge 的 MV3 环境下验证过
